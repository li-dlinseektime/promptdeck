随时取用，跨平台复用，内置 LA 专业模板
HTML + CSS + JS localStorage 纯前端，无后端 MVP 预计 2–3 周 可部署到 GitHub Pages
解决的三个痛点
多平台收藏混乱
从各处刷到的好 prompt 分散在不同 App，找不到、记不住
网络丢失重打
发出去没收到回复，又没存档，只能重新手打一遍长 prompt
跨平台复用麻烦
同一条 prompt 想在 Claude / ChatGPT / Midjourney 都用，没有统一出口

面试叙事脚本
我发现设计师在跨平台使用多个 AI 工具时，prompt 管理成本很高——好不容易写的长 prompt 会因网络问题丢失，收藏在各处的提示词散乱难找，现有工具要么面向开发者团队太重，要么只是个收藏夹太轻。我从自身痛点出发，做了一个轻量的 prompt 管理工具，内置景观设计专业模板，面向设计工作流。
这个叙事结构包含：发现问题 → 市场分析 → 差异化定位 → 构建解决方案 → 垂直领域壁垒

# PromptDeck

A minimal, local-first prompt management workspace for designers.

## What it does

PromptDeck helps designers manage AI prompts across platforms — save, organize, search, and reuse prompts without losing them to network issues or scattered notes.

**Core features**
- Draft area with auto-save (survives refresh)
- Save prompts with title, tags, and platform labels
- One-click copy to clipboard
- Filter by platform or tag (multi-select)
- Star/favorite prompts
- Built-in Landscape Architecture template pack

**No backend. No account. Data stays in your browser (localStorage).**

## Tech stack

Pure HTML + CSS + JavaScript, single file, zero dependencies.

1. Clone this repository.
